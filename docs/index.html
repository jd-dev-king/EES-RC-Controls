⚡ RC Circuit Transient Response Simulator

MATLAB Engineering Simulation Project

Project Overview

A MATLAB-based simulation that models capacitor charging and discharging behavior in a first-order RC circuit.

The project demonstrates transient response analysis, time constant calculations, and engineering visualization.

Engineering Model

RC Time Constant

τ = RC

Charging Response

V(t)=V₀(1-e-t/RC)

Discharging Response

V(t)=V₀e-t/RC
